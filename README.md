# About Junct (MIT)

Windows Explorer shell extension that makes folder sharing and mklink stupidly simple.

- **Paste junction** : creates a junction from copied folders.
- **Share to public** : shares folders by mklink through a configurable public location.

## Install

Download `Setup.exe` from the [latest release](../../releases/latest) and run it.

The installer lets you choose the commands to install and configure the public location.

For uninstall : from **Settings > Apps** or **Start menu > Junct > Uninstall Junct**.
